### Hey, I'm Omar.

Founder of **YU**. MIT Sloan '26. I build things that help people show up for themselves.

7 years ago I was 80 lbs overweight. I started with 7 minutes a day. That became the Boston Marathon, Ironman 70.3, and eventually MIT. None of it happened because I was exceptional. It happened because I was consistent.

Now I build tools around that idea.

---

#### What I'm building

**[Jerome7](https://github.com/odominguez7/Jerome7)** -- Daily 7-minute reset for builders. AI-generated breathwork, meditation, reflection. Same session for every builder on Earth, every day. Open source. Free forever. [jerome7.com](https://jerome7.com)

**[YU Shield](https://github.com/odominguez7/podman-hackathon)** -- AI burnout detection that runs entirely on your machine. 30-second daily check-in, IBM Granite 3.3 via Podman. Privacy is architectural, not aspirational.

**[CourtSync](https://github.com/odominguez7/Courtsync-Pickleboard)** -- AI pickleball match coordinator. Text "3.5 doubles tomorrow 6pm" on WhatsApp and it finds you a game. Gemini 2.0 Flash + Firestore + Twilio.

**[meetMIT](https://github.com/odominguez7/meetMIT)** -- AI-powered campus connections. Big Five personality matching turns free moments into real in-person meets. Built for MIT and Harvard.
